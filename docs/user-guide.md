# User Guide

## Getting Started

### Account Creation
1. Visit the application homepage
2. Click "Sign Up" in the top right corner
3. Choose your preferred sign-up method:
   - Email/Password
   - Google OAuth
4. Complete the registration process
5. Verify your email address

### First-Time Setup
1. Complete your profile information
2. Set up two-factor authentication (recommended)
3. Review and accept terms of service
4. Configure notification preferences

## User Roles and Permissions

### Regular User
- Access forms from admin
- View own submission history

### Administrator
- All Regular User permissions
- Create and manage organization forms
- Manage form submissions


### Super Administrator
- All Manager permissions
- System-wide access
- User role management
- Advanced security settings

## Form Creation

### Basic Form Creation
1. Click "Create New Form"
2. Enter form title and description
3. Choose form template (optional)
4. Start adding form fields

### Field Types
1. **Text Input**
   - Single-line text
   - Character limit options
   - Input validation

2. **Paragraph**
   - Multi-line text
   - Rich text formatting
   - Word count limit

3. **Multiple Choice**
   - Single selection
   - Multiple selection
   - Custom options
   - "Other" option

4. **Checkbox**
   - Multiple selections
   - Required options
   - Custom validation

5. **Dropdown**
   - Single selection
   - Custom options
   - Default value

6. **Image Upload**
